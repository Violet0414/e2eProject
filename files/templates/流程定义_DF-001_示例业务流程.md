# 流程定义：示例业务流程（虚构）

> 虚构示例：用于验证 dataflow-script-generate 技能闭环，页面路由均为不存在的占位路由。

- 流程ID: DF-001
- BASE_URL: http://10.10.40.18:10010
- 优先级: 高

## 节点1：填报提交

1. 打开页面 /business/#/demo-report
2. 填写数据
   | 字段 | 值 |
   | 姓名 | 张三 |
   | 经办人 | 李四 |
3. 点击按钮 保存
4. 校验：状态变更为 待审核
5. 校验：与第2步填写数据一致：姓名、经办人

## 节点2：审核

6. 打开页面 /business/#/demo-audit
7. 填写数据 { 姓名: ${姓名} }
8. 点击按钮 审核通过
9. 校验：状态变更为 已审核
10. 校验：与第2步填写数据一致：姓名、经办人
